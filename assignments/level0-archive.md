# Level 0 Archive Assignment

## Purpose

Archive and preserve stable project memory without turning it into a progress dashboard.

## Scope

Level 0 owns durable context:

- product identity
- source hierarchy
- safety invariants
- accepted architecture decisions
- stable terminology
- historical rationale that prevents repeated mistakes

## Inputs

- `AGENTS.md`
- `CONTEXT.md`
- `docs/01-product/*`
- `docs/04-decisions/*`
- `docs/03-engineering/schema-rls-matrix.md`

## Outputs

- Stable wiki summaries.
- Links to source-of-truth docs.
- Notes about invariants that must survive implementation churn.

## Out Of Scope

- Current issue status.
- Temporary task ordering.
- Daily progress notes.
- Closing issues or PRs.

## Success Check

An agent can read Level 0 output and avoid violating Fevio's privacy, confirmation, partner-projection, and medical-boundary rules before opening code.
