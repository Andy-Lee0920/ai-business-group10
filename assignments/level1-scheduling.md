# Level 1 Scheduling Assignment

## Purpose

Turn active project work into a clear daily operating plan without weakening issue closure discipline.

## Scope

Level 1 owns near-term scheduling:

- open issue scan
- open PR scan
- epic priority ordering
- Red -> Green child issue identification
- deployment and test-risk surfacing

## Focus Areas

- Home storyline / care-state hero epic
- notification-related issues
- navigation and IA issues
- failing tests
- deployment risks
- unresolved external settings

## Daily Output

1. Changes since yesterday
2. Top 3 priorities for today
3. Blockers or questions
4. Suggested next commit or PR

## Rules

- Do not close an issue while a known Red remains.
- Tie product behavior to URL-action-result Green conditions.
- Separate evidence from interpretation.
- Prefer child issues for specific Red -> Green transitions.
- Mention deployment gaps explicitly instead of implying completion.
