## 1. Problem

난임 치료 과정은 다음과 같은 복합적인 어려움을 동반한다.

### 일정 관리의 복잡성
- 병원 방문 일정이 불규칙하고 빈번함
- 방문 목적이 매번 다름 (진료 / 주사 / 검사 / 시술 등)
- 당일 일정 변경이 잦아 유연한 대응이 필요함

### 치료 프로토콜의 복잡성
- 복용 약, 주사, 질정 등 치료 방법이 다양하고 복잡함
- 약 이름이 유사하거나 생김새가 비슷해 혼동 발생
- 주사 투여 시간 등 정확한 타이밍이 시술 결과에 직접적 영향을 줌
- 놓칠 경우 시술 자체가 취소될 수 있음

### 부부 간 정보 비대칭
- 치료 과정은 부부 단위로 진행되지만 정보가 한쪽(주로 아내)에 집중됨
- 병원 방문 후 귀가해 전달하는 과정에서 정보 누락·왜곡 발생
- 파트너이 주사를 직접 놔줘야 하는 상황에서도 정확한 정보 전달이 어려움

### 결과
- 실수 및 스트레스 발생
- 부부 간 정보 비대칭으로 인한 감정적 갈등
- "나만 고생하는 것 같다"는 감정적 소진

## 2. Target User

### Primary
- 시험관(IVF) / 인공수정(IUI) 등 난임 치료 중인 부부
- 치료 초기부터 반복 시술 경험자까지 포함

### 특히 니즈가 높은 사용자
- 일정 및 약 복용 관리에 어려움을 느끼는 사용자
- 부부 간 정보 공유 및 역할 분담 니즈가 있는 사용자
- 파트너이 주사 투여에 직접 참여하는 부부

## 3. User Research

> 난임 치료 중인 주변 사용자 3명 심층 인터뷰 기반 (2025)

### 인터뷰이 A — 약 혼동 경험
처방받은 약이 여러 개인데 이름이 비슷하거나 생김새가 유사해 착각하는 경우 발생.
시술에 영향을 주는 주사를 잘못 이해하고 빠뜨린 경험이 있음.

**→ 도출:** 약 종류별 시각적 구분, 중요도 기반 경고 알림 필요

### 인터뷰이 B — 부부 정보 비대칭 경험
파트너이 주사를 직접 놔줘야 하는 상황인데, 아내 혼자 병원에서 들은 내용을 귀가 후 전달하는 과정에서 정보 누락·왜곡 발생.
"뭘 어떻게 해야 하는지 모르겠다"는 파트너 측 혼란이 반복됨.

**→ 도출:** 실시간 정보 공유 + 파트너용 간결한 액션 가이드 필요

### 인터뷰이 C — 감정 소진 경험
정보 관리, 병원 일정, 주사 준비까지 모두 혼자 감당하는 느낌.
"나만 고생하는 것 같아서 억울하다"는 감정적 부담이 누적됨.

**→ 도출:** 부부 역할 가시화 + 감정 기록 및 공유 기능 필요

## 4. Solution

> "난임 치료 전 과정을 부부가 함께 관리하는 앱"

### 핵심 컨셉
| 영역 | 해결 방향 |
|------|-----------|
| 일정 관리 | 불규칙한 병원 일정을 유연하게 등록·변경 |
| 약/주사 관리 | 실수 방지 + 정확한 타이밍 보장 |
| 부부 공유 | 실시간 정보 공유로 비대칭 해소 |
| 시술 기록 | 치료 여정의 체계적 기록 및 감정적 의미 부여 |

## 5. Core Features

### 5-1. 치료 일정 관리

병원 방문 일정을 유형별로 등록하고 유연하게 관리한다.

**기능 목록**
- 병원 방문 일정 등록
  - 방문 유형 선택: 진료 / 주사 / 검사 / 기타
- 일정 변경·취소 처리 (유연성 중요)
- 반복 일정 등록
- 당일 일정 빠른 추가

**핵심 원칙:** 현실적인 일정 변화에 유연하게 대응

---

### 5-2. 약 / 주사 관리

처방 기반으로 복용·투여 일정을 등록하고, 실수를 방지한다.

**기능 목록**
- 처방 기반 일정 등록
  - 약 종류, 투여 방식 (경구 / 주사 / 질정 등), 시간 설정
- 알림 기능
  - 정시 알림
  - 미복용/미투여 시 리마인드 재알림
- 완료 체크 및 히스토리 관리
- 약 종류별 시각적 구분 (색상·아이콘)
- 중요도 기반 경고 표시
  - 예: "⚠️ 이 주사는 놓치면 시술에 영향이 있어요"

**핵심 원칙:** 실수 방지 + 타이밍 보장

---

### 5-3. 부부 공유 기능

부부가 같은 정보를 실시간으로 확인하고 역할을 분담한다.

**기능 목록**
- 일정 실시간 공유
- 약/주사 완료 상태 공유
- 병원 동행 여부 표시
  - 예: "오늘 파트너 동행 / 아내 단독 방문"
- 역할 지정 기능
  - 예: "주사 관리: 파트너 담당 / 병원 방문: 아내 담당"
- 파트너 알림 연동
  - 상대방이 체크를 놓쳤을 때 파트너에게도 알림 발송

**핵심 원칙:** 정보 비대칭 해소 + 협업 구조 강화

---

### 5-4. 시술 기록 관리 (IVF 트래킹)

시술 과정을 회차별로 기록하고 전체 여정을 시각화한다.

**기능 목록**
- 난자 채취 개수 기록
- 수정 개수 기록
- 배아 이식 기록 (날짜별)
- 결과 기록
- 배아 사진 업로드
- 타임라인 형태 히스토리 제공 (회차별)

**핵심 원칙:** 과정의 기록 + 감정적 의미 부여

---

### 5-5. 온보딩 플로우

첫 진입 시 5분 이내에 핵심 설정을 완료할 수 있도록 설계한다.

**플로우**
1. 역할 선택 — 아내 / 파트너
2. 치료 단계 선택 — 검사 중 / 시험관 시작 / 인공수정 / 반복 시술 중
3. 현재 프로토콜 입력 — 약 이름 + 투여 방식 + 시간
4. 파트너 초대 — 링크 또는 코드 방식 (skip 허용)
5. 오늘 일정 자동 생성 확인

**핵심 원칙**
- 온보딩 완료까지 5분 이내
- 파트너 초대는 나중에도 가능 (강제하지 않음)
- 자주 쓰는 프로토콜 템플릿 제공으로 입력 부담 최소화

---

### 5-6. 오프라인 / 알림 실패 대응

주사 알림이 앱의 핵심인 만큼, 알림 미도달 시나리오에 대한 fallback을 설계한다.

**중요도별 알림 전략**

| 중요도 | 알림 방식 |
|--------|-----------|
| 일반 | 앱 푸시 알림 |
| 높음 (시술 영향 가능) | 앱 푸시 + 카카오 알림톡 / 문자 fallback |
| 파트너 연동 | 배우자 기기에 동시 발송 |

**미확인 알림 재전송 로직**
- 15분 내 체크 없음 → 재알림 발송
- 30분 내 체크 없음 → 파트너 기기에 알림 ("아내가 주사 확인을 못 했어요")

> **v1 결정 필요:** 카카오 알림톡 연동은 비용·개발 리소스가 필요하므로,
> v1에서는 푸시 + 재알림으로만 할지 여부를 결정해야 함.

---

### 5-7. 데이터 민감성 및 보안 정책

난임 치료 기록, 배아 사진, 감정 일기는 최고 수준의 민감 개인 의료 정보다.
초기에 정책을 정해두지 않으면 사용자 신뢰 손실 및 법적 리스크로 이어질 수 있다.

**정의 필요한 항목**

| 항목 | 정책 방향 |
|------|-----------|
| 데이터 저장 | 서버 암호화 저장 (배아 사진 등 미디어 포함) |
| 접근 제어 | 부부 외 제3자 접근 차단 |
| 연결 해제 | 파트너 연결 해제 시 상대방 데이터 접근 즉시 차단 |
| 계정 탈퇴 | 탈퇴 시 즉시 삭제 또는 30일 유예 후 삭제 선택 제공 |
| 미디어 삭제 | 배아 사진 등 별도 다운로드 후 삭제 유도 |

> **법적 검토 필요:** 국내 개인정보보호법 / 의료법 적용 범위 확인.
> 앱이 의료기기로 분류되는지 여부를 초기에 확인 권장.

## 6. Differentiation

### 6-1. 실수 방지 강화
- 복용 미완료 시 반복 리마인드
- 중요 주사에 경고 표시 (놓치면 시술 영향 명시)
- 중요도 기반 UX 제공

### 6-2. 감정 기록 및 공유
- 일별 컨디션 / 감정 기록
- 배우자와 자동 공유
  - 예: "오늘 힘들었어요", "주사 때문에 아팠어요"
- 단순 관리 앱 → 관계 케어 기능으로 확장

### 6-3. 병원 프로토콜 자동 생성
- 처방 입력 시 일정 자동 생성
  - 예: 3일간 주사 + 5일차 검사 → 자동 캘린더 생성
- 사용자 입력 부담 최소화

### 6-4. 시술 여정 타임라인
- 시도 횟수별 기록 및 결과 추적
- 전체 치료 여정 시각화

### 6-5. 부부 역할 분담
- 역할 지정 기능 (파트너 담당 / 아내 담당)
- 협업 구조 강화

## 7. UX Flow

```
앱 진입
  └─ 오늘 일정 확인
       └─ 약/주사 알림 수신
            └─ 완료 체크
                 └─ 부부 공유 상태 확인
                      └─ 시술 결과 기록
```

## 8. Non-Goals

다음 항목은 의도적으로 v1 범위에서 제외한다.

| 항목 | 이유 |
|------|------|
| 의료 조언 / 진단 기능 | 의료기기 규제 리스크 |
| 병원 예약 직접 연동 | 병원별 시스템 상이, 개발 복잡도 높음 |
| 커뮤니티 / SNS 기능 | 핵심 가치와 거리가 멀고 초기 집중 필요 |
| 해외 사용자 지원 | 국내 시장 검증 우선 |
| AI 기반 치료 추천 | 의료법 검토 필요, v2 이후 고려 |

## 9. MVP Scope

> 3개 핵심 기능으로 빠르게 검증한다.

### v1 — Must Have
- [ ] 치료 일정 등록·변경·알림
- [ ] 약/주사 관리 + 중요도 기반 알림 + 완료 체크
- [ ] 부부 연결 및 일정/약 상태 실시간 공유
- [ ] 기본 온보딩 플로우

### v2 — Should Have
- [ ] 시술 기록 관리 (IVF 트래킹)
- [ ] 감정 기록 및 공유
- [ ] 병원 프로토콜 자동 생성
- [ ] 카카오 알림톡 fallback

### v3 — Nice to Have
- [ ] 시술 여정 타임라인 시각화
- [ ] 부부 역할 분담 고도화
- [ ] 배아 사진 업로드
