# ADR 0012 — Result Protection Mode after negative beta

## Status
Accepted

## Context

A negative beta result is not a normal task-completion state. It is a high-vulnerability moment: patients often blame their body, replay embryo grades and numbers, lose trust in the clinic, experience a partner temperature mismatch, and feel pressure to decide on the next cycle immediately.

Fevio must not convert that moment into productivity, upsell, diagnosis, or next-cycle pressure.

## Decision

When `beta_test_recorded` has `resultStatus: 'negative'`, Fevio enters Result Protection Mode.

Canonical cycle outcome fields:

```ts
cycle_outcome: 'negative'
cycle_status: 'closed_for_now' | 'review_available' | 'next_cycle_planning'
review_visibility: 'hidden_until_user_opens'
emotional_mode_until: string | null
```

The product sequence is:

```text
C immediate → B delayed 48h → A ambient
```

### C immediate — protection first

Immediately after the negative result, the home surface shows a quiet protection state.

Required posture:

- `오늘은 아무것도 결정하지 않아도 돼요.`
- `이번 결과는 당신의 잘못으로 설명되지 않아요.`
- Single CTA: `오늘은 조용히 두기`.
- Partner mode: `결과에 대해 먼저 말하지 않기 · 오늘 결정할 일을 만들지 않기`.

### B delayed 48h — cycle record reframing

After 48 hours, Fevio may make a cycle record available, but the card remains hidden until the user opens it.

The record title is `이번 cycle에서 확인된 것`.

The record contains confirmed facts and user-entered observations only:

- stimulation dates;
- retrieval date and counts if recorded;
- fertilization/culture/freeze/transfer events if recorded;
- beta result;
- confirmed clinic instructions;
- medication execution and user notes.

It is not a failure report and not an analysis report.

### A ambient — quieting continues

During `emotional_mode_until`:

- critical/important non-medication nudges are suppressed;
- routine medication reminders can continue;
- partner surface stays in quiet support mode;
- next-cycle affordances remain hidden unless the user explicitly opens planning.

## Product principle

Result Protection Mode is always free. It cannot sit behind a paywall, Cycle Pass check, subscription check, or promotional gate.

## Consequences

- Fevio becomes a care OS rather than a cycle productivity app.
- Negative results are handled as a protected transition, not a conversion opportunity.
- Cycle data remains useful after failure because it is reframed as confirmed context for later review.
- The user controls when, or whether, to open review and next-cycle planning.

### Consequences.Forbidden

- next cycle preparation push immediately after a negative result.
- failure-cause analysis generated by Fevio.
- embryo grade scoring or success/failure point scoring.
- HCG prediction, symptom diagnosis, or probability projection.
- clinic blame suggestions or comparison content.
- automatic partner result broadcasting.
- paywall, Cycle Pass upsell, or subscription prompt around Result Protection.
- automatic display of the Cycle Record while review_visibility is 'hidden_until_user_opens'.
