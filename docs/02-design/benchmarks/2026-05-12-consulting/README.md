# Fevio consulting benchmark pack — 2026-05-12

These images are benchmark references for Fevio's UX reset issues. They are not implementation screenshots. They define the quality bar for phase-distinct layout, partner role translation, and patient context review.

## Core benchmark lessons

1. **The problem is information overload, not user carelessness.** The UI must stop making users manage raw care state.
2. **Care phase is not a theme.** Injection, clinic, and waiting screens must have different centers of gravity.
3. **InjectionDay is time-first.** The time/ring instrument should dominate; supporting content moves below.
4. **Partner surface is a joint checklist, not a mirror.** Partner sees role + concrete action, not raw projection data.
5. **ClinicDay is a patient context review.** It should help the patient recall recent care execution before the visit and capture confirmed next instructions after the visit.
6. **WaitingDay is space-first.** The layout should reduce checking pressure; whitespace is part of the intervention.
7. **Layout system must keep one source of truth while allowing different silhouettes.** Shared tokens, different phase compositions.
