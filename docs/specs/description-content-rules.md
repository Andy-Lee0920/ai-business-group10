# Description Content Rules — Issue #54

`care_action_cards.description`은 사용자가 병원 지시를 실행 카드로 정리한 텍스트다. 파트너 화면으로 전달될 수 있으므로, 실행 단서와 의료 판단 경계를 분리한다.

## 허용 카테고리

### 행동: 투여/복용/방문

- `고날에프 주사`
- `프로게스테론 복용`
- `오비드렐 맞기`
- `채혈 방문`
- `초음파 검사 방문`

### 시간: 시각/주기

- `오늘 21시`
- `아침 식후`
- `매일 같은 시간`
- `3일간`
- `병원 방문 전`

### 종류: 약/주사명

- `고날에프`
- `오비드렐`
- `프로게스테론`
- `루티너스`
- `질정`

### 횟수

- `1회`
- `하루 2번`
- `아침/저녁`
- `오늘 한 번`
- `3일 반복`

## 금지 카테고리

금지 카테고리는 저장 차단이 아니라 확인 경고 대상이다. 사용자가 병원 지시를 그대로 옮긴 경우도 있을 수 있기 때문에 confirm 화면은 경고만 표시하고, 사용자는 “그래도 저장”으로 진행할 수 있다.

### 용량 조정 표현

- `용량을 올리세요`
- `용량을 내리세요`
- `용량 증량`
- `용량 감량`
- `75mg로 올려`
- `두 배로 늘려`

### 진단/병명 추론

- `PCOS 증상이 의심`
- `다낭성 같습니다`
- `자궁내막증 진단`
- `난소기능저하입니다`
- `이 증상은 정상입니다`
- `감염인 것 같아요`

### 성공률 단정

- `성공 가능성이 높아요`
- `성공률이 낮아요`
- `임신 가능성 80%`
- `이번엔 성공될 거예요`
- `착상 잘 될 거예요`
- `임신 확정`

### 치료 전략 변경

- `병원에 가지 않아도 됩니다`
- `프로토콜 변경`
- `치료 방향을 바꾸세요`
- `이식 취소`
- `채취를 미루세요`
- `처방을 대체하세요`

## UI 규칙

- Confirm 화면에서 후보 설명별로 경고 배지를 표시한다.
- 경고는 차단이 아니다.
- 파트너 화면은 Rule #27-A에 따라 사용자가 confirm한 `description`만 그대로 표시한다.
- LLM 또는 앱이 의료 판단을 생성하거나 수정하지 않는다.
