## Product meaning for Fevio

**Confirm now has evidence-anchored inline quotes.** The split domain stores UTF-16 source offsets so the confirm UI can show the user the exact phrase from their original clinic memo that generated each candidate. This directly addresses the care card trust problem: confirmed actions trace back to what the clinic said, not what the model reconstructed.

**Push permission is now behind an explicit CTA.** Notification permission is no longer requested on page load. `PushPermissionCta` only appears after PWA install readiness is detected, and iOS install-first copy is shown on iOS. This respects the "calm by default" product posture and the explicit user-action boundary.

**Reminder dispatch is now idempotent.** Under scheduler retry, the same card+time+channel combination cannot be dispatched twice. CRON_SECRET is the sole scheduler auth path, removing the service-role fallback that weakened failure attribution.

**Firebase is fully removed.** Survey storage, the Firebase package, and the associated spec are gone. The product is now Supabase-only, which closes a backend confusion risk and reduces the `node_modules` footprint.
