### Key learnings
1. vitest 4.x removed the `all: true` coverage option. The `include` glob pattern alone is sufficient — files matching src/**/*.{ts,tsx} appear in the report even if not imported by any test (at 0%). No separate `all: true` flag needed.
2. `coverage` block must be inside `test`, not at the root defineConfig level. Root-level coverage causes TS2769 "does not exist in type ViteUserConfigExport".
3. npm install @vitest/coverage-v8 fails with "Cannot read properties of null (reading 'edgesOut')" on this repo — use --legacy-peer-deps flag.
4. Pin @vitest/coverage-v8 to exact version matching vitest (both 4.1.5). Caret range installs 4.1.7 which causes peer dep mismatch.
5. reportOnFailure: true is needed because 2 pre-existing test failures suppress the coverage table by default. The failures are: (a) CRLF mismatch in ADR file tests on Windows, (b) syntax error in deploy-regression-guard.test.ts. These are pre-existing, not introduced by this session.
